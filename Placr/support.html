技术支持

需要 macOS 15 或更新版本

遇到问题或有功能建议，请发送邮件至 imhccn@gmail.com。

搜不到境外地点怎么办？

在中国大陆使用时，Apple 地图可能不返回境外搜索结果，这是系统层面的限制。你可以在“设置 → 地点搜索”中填入自己的 Google Maps API Key；Apple 地图没有结果时，Placr 会自动改用 Google。

怎样获取 Google Maps API Key？

在 Google Cloud 控制台创建项目，启用 Places API (New)，生成 API Key 后粘贴到 Placr 设置中。

这个 Key 属于你，搜索请求会计入你的 Google 账户。建议在 Google Cloud 中限制该 Key 只能使用 Places API，并设置预算提醒。

API Key 保存在哪里？

它保存在 macOS 钥匙串中，不会出现在草稿、操作记录或导出文件里。你可以随时在 Placr 设置中移除；钥匙串服务名是 cn.chenhk.placr.google-places。

怎样撤销照片权限？

打开“系统设置 → 隐私与安全性 → 照片”，关闭 Placr。撤销权限不会删除照片，也不会撤销已经写入的位置。

怎样删除 Placr 的本机数据？

先退出 Placr。在访达选择“前往 → 前往文件夹”，输入 ~/Library/Containers/cn.chenhk.placr，将该文件夹移到废纸篓。Google API Key 需要另外在 Placr 设置或“钥匙串访问”中移除。

删除本机数据会同时删除操作记录，也就失去用 Placr 恢复旧位置的依据。需要恢复时请先恢复，再删除。

写错位置后能撤销吗？

可以。打开“操作记录”，选择那次写入并恢复。Placr 会先确认照片当前的位置仍然等于当时写入的值，不会覆盖你后来在“照片”中做出的修改。

Placr 会修改或删除照片吗？

不会删除照片，也不会改动位置以外的元数据。位置只会在你完成候选确认和最终批量确认后写入。

为什么访达中的图标没有变化？

macOS 只允许应用在运行时替换 Dock 和应用切换器图标；访达图标由代码签名固定，无法在运行时更改。

怎样切换界面语言？

在“设置 → 语言”中选择，或选择跟随系统。Placr 支持简体中文、繁體中文（台灣）、繁體中文（香港）、日本語和 English，切换后需要重新启动。

找不到國外地點怎麼辦？

在中國大陸使用時，Apple 地圖可能不會傳回境外搜尋結果，這是系統層級的限制。你可以在「設定 → 地點搜尋」中輸入自己的 Google Maps API 金鑰；Apple 地圖沒有結果時，Placr 會自動改用 Google。

如何取得 Google Maps API 金鑰？

在 Google Cloud 控制台建立專案，啟用 Places API (New)，產生 API 金鑰後貼到 Placr 設定中。

這個金鑰屬於你，搜尋請求會計入你的 Google 帳戶。建議在 Google Cloud 將金鑰限制為只能使用 Places API，並設定預算通知。

API 金鑰儲存在哪裡？

它會保存在 macOS 鑰匙圈中，不會出現在草稿、操作記錄或匯出檔案。你可以隨時在 Placr 設定中移除；鑰匙圈服務名稱是 cn.chenhk.placr.google-places。

如何撤銷照片權限？

開啟「系統設定 → 隱私權與安全性 → 照片」，關閉 Placr。撤銷權限不會刪除照片，也不會撤銷已寫入的位置。

如何刪除 Placr 的本機資料？

先結束 Placr。在 Finder 選擇「前往 → 前往檔案夾」，輸入 ~/Library/Containers/cn.chenhk.placr，再將該檔案夾移到垃圾桶。Google API 金鑰需要另外在 Placr 設定或「鑰匙圈存取」中移除。

刪除本機資料也會刪除操作記錄，因此無法再用 Placr 還原舊位置。如需還原，請先還原再刪除。

寫錯位置後可以復原嗎？

可以。開啟「操作記錄」，選擇該次寫入並還原。Placr 會先確認照片目前的位置仍與當時寫入的值相同，不會覆蓋你後來在「照片」中所做的修改。

Placr 會修改或刪除照片嗎？

不會刪除照片，也不會更動位置以外的中繼資料。只有在你完成候選確認與最後的批次確認後才會寫入位置。

為什麼 Finder 中的圖示沒有改變？

macOS 只允許 App 在執行期間替換 Dock 與 App 切換器圖示；Finder 圖示由程式碼簽署固定，無法在執行期間更改。

如何切換介面語言？

在「設定 → 語言」中選擇，或選擇跟隨系統。Placr 支援簡體中文、繁體中文（台灣）、繁體中文（香港）、日本語與 English，切換後需要重新啟動。

海外の場所が検索できない場合

中国本土から利用すると、Apple マップが国外の検索結果を返さない場合があります。これはシステム側の制限です。「設定 → 場所検索」で自分の Google Maps API キーを設定すると、Apple マップに結果がないときだけ自動的に Google を利用します。

Google Maps API キーの取得方法

Google Cloud コンソールでプロジェクトを作成し、Places API (New) を有効にして、作成した API キーを Placr の設定に貼り付けます。

キーはご自身のもので、検索はご自身の Google アカウントに計上されます。Places API だけに利用を制限し、予算アラートを設定することをおすすめします。

API キーの保存場所

macOS のキーチェーンに保存され、下書き、操作履歴、書き出したファイルには含まれません。Placr の設定からいつでも削除できます。キーチェーンのサービス名は cn.chenhk.placr.google-places です。

写真へのアクセスを取り消す方法

「システム設定 → プライバシーとセキュリティ → 写真」で Placr をオフにします。権限を取り消しても写真は削除されず、すでに書き込んだ位置情報も元には戻りません。

Placr の端末内データを削除する方法

Placr を終了し、Finder の「移動 → フォルダへ移動」で ~/Library/Containers/cn.chenhk.placr を開き、そのフォルダをゴミ箱へ移動します。Google API キーは Placr の設定または「キーチェーンアクセス」で別途削除してください。

端末内データを削除すると操作履歴も消え、Placr から以前の位置に復元できなくなります。必要な復元を先に済ませてください。

間違った位置を元に戻せますか？

できます。「操作履歴」を開き、対象の書き込みを選んで復元してください。Placr は現在の位置が書き込み時の値と同じことを確認するため、その後「写真」で行った変更を上書きしません。

写真を変更または削除しますか？

写真を削除せず、位置情報以外のメタデータも変更しません。候補の確認と最後の一括確認を終えた場合にだけ位置情報を書き込みます。

Finder のアイコンが変わらない理由

macOS では実行中に変更できるのは Dock とアプリ切り替え画面のアイコンだけです。Finder のアイコンはコード署名で固定されているため変更できません。

表示言語の変更方法

「設定 → 言語」で選ぶか、システム設定に従うよう指定します。簡体字中国語、繁体字中国語（台湾・香港）、日本語、英語に対応しており、変更後は再起動が必要です。

Places abroad do not appear in search

When Placr is used from mainland China, Apple Maps may not return results outside the region. This is a system-level limitation. Add your own Google Maps API key under Settings → Place Search, and Placr will use Google only when Apple Maps returns no result.

Get a Google Maps API key

Create a project in the Google Cloud console, enable Places API (New), generate an API key, and paste it into Placr Settings.

The key belongs to you, and searches count against your Google account. Restrict the key to Places API and set a budget alert in Google Cloud.

Where the API key is stored

It is kept in the macOS Keychain and never appears in drafts, operation history, or exported files. You can remove it at any time in Placr Settings. Its Keychain service name is cn.chenhk.placr.google-places.

Revoke Photos access

Open System Settings → Privacy & Security → Photos and turn off Placr. Revoking access does not delete photos or undo locations that have already been written.

Delete Placr’s local data

Quit Placr. In Finder, choose Go → Go to Folder, enter ~/Library/Containers/cn.chenhk.placr, and move that folder to the Trash. Remove the Google API key separately in Placr Settings or Keychain Access.

Deleting local data also deletes the operation history, so Placr will no longer be able to restore earlier locations. Complete any restoration first.

Undo a location written by mistake

Open Operation History, select the write, and restore it. Placr first verifies that the current location still matches the value it wrote, so it will not overwrite a change you made later in Photos.

Does Placr change or delete photos?

It never deletes photos and never changes metadata other than location. A location is written only after both the candidate confirmation and final batch confirmation.

Why the Finder icon does not change

macOS lets an app change only its Dock and app-switcher icon at runtime. The icon in Finder is fixed by the code signature and cannot be changed while the app runs.

Change the interface language

Choose a language under Settings → Language, or follow the system. Placr supports Simplified Chinese, Traditional Chinese for Taiwan and Hong Kong, Japanese, and English. Restart the app after changing it.
