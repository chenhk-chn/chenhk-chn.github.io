技术支持

需要 macOS 15 或更新版本

遇到问题或有功能建议，请发送邮件至 imhccn@gmail.com。

搜不到境外地点怎么办？

地点搜索由 Apple 地图提供。在中国大陆使用时，Apple 地图可能不返回部分境外地点；请尝试更具体的地名或地址。

怎样撤销照片权限？

打开“系统设置 → 隐私与安全性 → 照片”，关闭 Placr。撤销权限不会删除照片，也不会撤销已经写入的位置。

怎样删除 Placr 的本机数据？

先退出 Placr。在访达选择“前往 → 前往文件夹”，输入 ~/Library/Containers/cn.chenhk.placr，将该文件夹移到废纸篓。

删除本机数据会同时删除操作记录，也就失去用 Placr 恢复旧位置的依据。需要恢复时请先恢复，再删除。

写错位置后能撤销吗？

可以。打开“操作记录”，选择那次写入并恢复。Placr 会先确认照片当前的位置仍然等于当时写入的值，不会覆盖你后来在“照片”中做出的修改。

Placr 会修改或删除照片吗？

不会删除照片，也不会改动位置以外的元数据。位置只会在你完成候选确认和最终批量确认后写入。

为什么访达中的图标没有变化？

macOS 只允许应用在运行时替换 Dock 和应用切换器图标；访达图标由代码签名固定，无法在运行时更改。

怎样切换界面语言？

在“设置 → 语言”中选择，或选择跟随系统。Placr 支持简体中文、繁体中文（台湾/香港）、日语、英语、德语、西班牙语、法语、意大利语、葡萄牙语（巴西）和韩语，切换后需要重新启动。

找不到國外地點怎麼辦？

地點搜尋由 Apple 地圖提供。在中國大陸使用時，Apple 地圖可能不會傳回部分境外地點；請嘗試更具體的地名或地址。

如何撤銷照片權限？

開啟「系統設定 → 隱私權與安全性 → 照片」，關閉 Placr。撤銷權限不會刪除照片，也不會撤銷已寫入的位置。

如何刪除 Placr 的本機資料？

先結束 Placr。在 Finder 選擇「前往 → 前往檔案夾」，輸入 ~/Library/Containers/cn.chenhk.placr，再將該檔案夾移到垃圾桶。

刪除本機資料也會刪除操作記錄，因此無法再用 Placr 還原舊位置。如需還原，請先還原再刪除。

寫錯位置後可以復原嗎？

可以。開啟「操作記錄」，選擇該次寫入並還原。Placr 會先確認照片目前的位置仍與當時寫入的值相同，不會覆蓋你後來在「照片」中所做的修改。

Placr 會修改或刪除照片嗎？

不會刪除照片，也不會更動位置以外的中繼資料。只有在你完成候選確認與最後的批次確認後才會寫入位置。

為什麼 Finder 中的圖示沒有改變？

macOS 只允許 App 在執行期間替換 Dock 與 App 切換器圖示；Finder 圖示由程式碼簽署固定，無法在執行期間更改。

如何切換介面語言？

在「設定 → 語言」中選擇，或選擇跟隨系統。Placr 支援簡體中文、繁體中文（台灣／香港）、日語、英語、德語、西班牙語、法語、義大利語、葡萄牙語（巴西）與韓語，切換後需要重新啟動。

海外の場所が検索できない場合

場所の検索には Apple マップを使用します。中国本土から利用する場合、一部の海外の場所が返されないことがあります。より具体的な地名や住所をお試しください。

写真へのアクセスを取り消す方法

「システム設定 → プライバシーとセキュリティ → 写真」で Placr をオフにします。権限を取り消しても写真は削除されず、すでに書き込んだ位置情報も元には戻りません。

Placr の端末内データを削除する方法

Placr を終了し、Finder の「移動 → フォルダへ移動」で ~/Library/Containers/cn.chenhk.placr を開き、そのフォルダをゴミ箱へ移動します。

端末内データを削除すると操作履歴も消え、Placr から以前の位置に復元できなくなります。必要な復元を先に済ませてください。

間違った位置を元に戻せますか？

できます。「操作履歴」を開き、対象の書き込みを選んで復元してください。Placr は現在の位置が書き込み時の値と同じことを確認するため、その後「写真」で行った変更を上書きしません。

写真を変更または削除しますか？

写真を削除せず、位置情報以外のメタデータも変更しません。候補の確認と最後の一括確認を終えた場合にだけ位置情報を書き込みます。

Finder のアイコンが変わらない理由

macOS では実行中に変更できるのは Dock とアプリ切り替え画面のアイコンだけです。Finder のアイコンはコード署名で固定されているため変更できません。

表示言語の変更方法

「設定 → 言語」で選ぶか、システム設定に従うよう指定します。簡体字中国語、繁体字中国語（台湾・香港）、日本語、英語、ドイツ語、スペイン語、フランス語、イタリア語、ポルトガル語（ブラジル）、韓国語に対応しており、変更後は再起動が必要です。

Places abroad do not appear in search

Place search is provided by Apple Maps. When Placr is used from mainland China, some places abroad may not appear; try a more specific place name or address.

Revoke Photos access

Open System Settings → Privacy & Security → Photos and turn off Placr. Revoking access does not delete photos or undo locations that have already been written.

Delete Placr’s local data

Quit Placr. In Finder, choose Go → Go to Folder, enter ~/Library/Containers/cn.chenhk.placr, and move that folder to the Trash.

Deleting local data also deletes the operation history, so Placr will no longer be able to restore earlier locations. Complete any restoration first.

Undo a location written by mistake

Open Operation History, select the write, and restore it. Placr first verifies that the current location still matches the value it wrote, so it will not overwrite a change you made later in Photos.

Does Placr change or delete photos?

It never deletes photos and never changes metadata other than location. A location is written only after both the candidate confirmation and final batch confirmation.

Why the Finder icon does not change

macOS lets an app change only its Dock and app-switcher icon at runtime. The icon in Finder is fixed by the code signature and cannot be changed while the app runs.

Change the interface language

Choose a language under Settings → Language, or follow the system. Placr supports Simplified Chinese, Traditional Chinese for Taiwan and Hong Kong, Japanese, English, German, Spanish, French, Italian, Brazilian Portuguese, and Korean. Restart the app after changing it.

Warum das Finder-Symbol sich nicht ändert

macOS erlaubt einer App zur Laufzeit nur Dock- und App-Umschalter-Symbol zu ändern. Das Symbol im Finder ist durch die Codesignatur festgelegt und lässt sich während der Laufzeit nicht ändern.

Nach dem Wechsel ist ein Neustart nötig.

사진 접근 권한 철회하기

'시스템 설정 → 개인정보 보호 및 보안 → 사진'에서 Placr을 끕니다. 권한을 철회해도 사진이 삭제되지 않고 이미 기록된 위치가 되돌려지지도 않습니다.

Placr 로컬 데이터 삭제하기

Placr을 종료한 뒤 Finder에서 '이동 → 폴더로 이동'을 골라 ~/Library/Containers/cn.chenhk.placr를 입력하고 그 폴더를 휴지통으로 옮깁니다.

로컬 데이터를 삭제하면 작업 기록도 함께 사라져 Placr에서 이전 위치를 복원할 수 없게 됩니다. 필요한 복원을 먼저 마치세요.

잘못 기록한 위치 되돌리기

작업 기록을 열고 해당 기록을 골라 복원하세요. Placr는 현재 위치가 기록 당시 값과 같은지 먼저 확인하므로, 이후 사진 앱에서 한 변경을 덮어쓰지 않습니다.

Placr는 사진을 수정하거나 삭제하나요?

사진을 삭제하지 않고 위치 외의 메타데이터도 바꾸지 않습니다. 위치는 후보 확인과 최종 일괄 확인을 마친 뒤에만 기록됩니다.

Finder 아이콘이 바뀌지 않는 이유
