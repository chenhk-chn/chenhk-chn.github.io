技术支持

需要 macOS 15 或更新版本

遇到问题或有功能建议，随时写信到 imhccn@gmail.com。下面是几个常见问题。

常见问题

搜不到境外的地点怎么办？

在中国大陆使用时，Apple 地图不返回境外的搜索结果，这是系统层面的限制，应用无法绕过。

解决办法是在「设置 → 地点搜索」中填入你自己的 Google Maps API Key。填好之后，Apple 地图搜不到的时候会自动改用 Google 查询，日常的境内搜索仍然走 Apple 地图。

Google Maps API Key 怎么获取？

在 Google Cloud 控制台创建项目，启用 Places API (New)，然后生成一个 API Key 粘贴到 Placr 的设置里。

这个 Key 属于你自己，搜索请求会计入你的 Google 账户。Google 为地图服务提供了每月免费额度，超出部分按其定价收费。建议在控制台为该 Key 设置用量上限。

Key 保存在哪里？安全吗？

保存在 macOS 钥匙串中，和其他应用的密码同等待遇。它不会出现在草稿、操作记录或任何导出文件里。你可以随时在设置中移除。

写错位置了，能撤销吗？

可以。每次写入前，Placr 都会把照片原来的位置记录下来。打开「操作记录」，选中那次写入，点击恢复即可回到写入前的状态——对本来就没有位置的照片来说，就是恢复为没有位置。

Placr 会修改或删除我的照片吗？

不会删除照片，也不会改动位置以外的任何元数据。位置只在你于确认页面明确同意后才会写入。

换了 Dock 图标，为什么访达里还是原来的？

这是 macOS 的限制。应用在运行时只能替换 Dock 和应用切换器中显示的图标；访达里看到的图标由代码签名固定，无法在运行时更改。

怎么切换界面语言？

在「设置 → 语言」中选择，或者选「跟随系统」。Placr 提供简体中文、繁體中文（台灣）、繁體中文（香港）、日本語和 English。切换后需要重新启动应用生效。

为什么有些照片的时区看起来不对？

照片记录的是绝对拍摄时刻。Placr 在比较时间时使用绝对时刻，同时在卡片上分别显示候选地点的时区和参考照片的原时区，方便你确认是不是同一段行程。

Support

Requires macOS 15 or later

For problems or feature requests, email imhccn@gmail.com. A few common questions are answered below.

Frequently asked

Why can't I find places outside my country?

When used from mainland China, Apple Maps does not return results for places abroad. This is a platform-level limitation the app cannot work around.

The workaround is to enter your own Google Maps API key under Settings → Place search. Once it is set, Placr falls back to Google whenever Apple Maps finds nothing, while everyday local searches still go through Apple Maps.

How do I get a Google Maps API key?

Create a project in the Google Cloud console, enable Places API (New), then generate an API key and paste it into Placr's settings.

The key is yours, and search requests are billed to your Google account. Google provides a monthly free allowance for Maps services and charges beyond it according to their pricing. Setting a usage cap on the key in the console is recommended.

Where is the key stored?

In the macOS Keychain, the same place other apps keep passwords. It never appears in drafts, operation history, or any exported file, and you can remove it from Settings at any time.

Can I undo a location I wrote by mistake?

Yes. Placr records each photo's original location before every write. Open the operation history, select that write, and restore it. For photos that had no location to begin with, restoring returns them to having no location.

Does Placr modify or delete my photos?

It never deletes photos and never changes metadata other than location. A location is written only after you explicitly approve it on the confirmation screen.

I changed the Dock icon, but Finder still shows the old one.

That is a macOS limitation. An app can replace the icon shown in the Dock and the app switcher at runtime, but the icon Finder displays is fixed by the code signature and cannot be changed while the app runs.

How do I change the language?

Pick one under Settings → Language, or choose to follow the system. Placr ships Simplified Chinese, Traditional Chinese (Taiwan), Traditional Chinese (Hong Kong), Japanese, and English. Restart the app for the change to take effect.

Why do some time zones look wrong?

A photo records an absolute moment in time. Placr compares times as absolute moments, and each card shows the candidate place's time zone alongside the reference photo's original time zone, so you can tell whether they belong to the same trip.
