隐私政策

最后更新：2026 年 7 月

Placr 完全在你的 Mac 上运行。它没有开发者服务器，不需要注册账号，开发者也收不到你的照片或使用记录。

不收集的内容

Placr 不会向开发者控制的服务器收集、存储或传输个人信息。应用没有分析统计、崩溃上报、广告、跨应用追踪，也没有第三方数据收集 SDK。

照片

在你授权后，Placr 会读取照片的拍摄时间、位置和缩略图，用来找出缺少位置的照片、按时间分组并显示参考照片。所有处理都在你的 Mac 上完成，照片本身不会离开设备。

只有经过候选确认和最终批量确认后，Placr 才会写入位置。它不会删除照片，也不会修改位置以外的元数据。写入前的原位置会保存在本机操作记录中，供你恢复。

地点搜索与第三方服务

搜索地点时，Placr 只发送你输入的文字；若有参考坐标，还会发送一个大致的搜索区域。照片、照片缩略图和操作记录不会发送。

默认搜索由 Apple 地图（MapKit）处理，适用 Apple 的隐私政策。如果你主动提供自己的 Google Maps API Key，而且 Apple 地图没有结果，Placr 才会请求 Google Places，适用 Google 的隐私政策。

Placr 只向这些服务提供完成当前搜索所需的最少信息，不会出售数据，也不会允许将请求用于开发者的广告或用户画像。

本机存储与保留期限

图库快照、审阅草稿、操作记录、时区缓存和偏好设置保存在 Placr 的沙盒容器中，直到你删除相应文件。Google Maps API Key 单独保存在 macOS 钥匙串中，直到你在 Placr 设置或“钥匙串访问”中移除。

删除 App 不一定会自动删除沙盒容器或钥匙串项目。下面提供了完整删除方法。

撤销权限与删除数据

  • 撤销照片访问：打开“系统设置 → 隐私与安全性 → 照片”，关闭 Placr。
  • 移除 Google API Key：在 Placr 的地点搜索设置中选择移除；也可以在“钥匙串访问”中删除服务名为 cn.chenhk.placr.google-places 的项目。
  • 删除 Placr 本机数据：退出 Placr，在访达选择“前往 → 前往文件夹”，输入 ~/Library/Containers/cn.chenhk.placr，然后将该文件夹移到废纸篓。

撤销照片权限或删除本机数据不会撤销已经写入照片的位置。若要恢复，请先在 Placr 的操作记录中执行恢复，再删除本机数据。

儿童

Placr 不面向儿童设计，也不会收集年龄或其他个人信息。

政策变更

如果本政策发生变化，本页顶部的日期会更新；重大变化也会在应用内提示。

联系方式

如有隐私问题，请发送邮件至 imhccn@gmail.com。

プライバシーポリシー

最終更新：2026 年 7 月

Placr はすべて Mac 上で動作します。開発者が運営するサーバーもアカウント登録もなく、写真や利用履歴が開発者に送られることはありません。

収集しない情報

Placr は、開発者が管理するサーバーへ個人情報を収集、保存、送信しません。解析、クラッシュレポート、広告、アプリ横断トラッキング、第三者のデータ収集 SDK は一切ありません。

写真

許可を得た後、Placr は撮影時刻、位置情報、サムネイルを読み取り、位置情報のない写真の抽出、時刻によるグループ分け、参考写真の表示に使います。処理はすべて Mac 上で行われ、写真そのものが端末の外へ送られることはありません。

候補を確認し、最後の一括確認を行った場合にだけ位置情報を書き込みます。写真の削除や、位置情報以外のメタデータの変更は行いません。書き込み前の位置は、復元できるよう端末内の操作履歴に保存されます。

場所検索と第三者サービス

場所を検索するときに送信するのは、入力した文字列だけです。参考座標がある場合は、検索精度を上げるため大まかな検索範囲も送信します。写真、サムネイル、操作履歴は送信しません。

通常の検索は Apple マップ（MapKit）が処理し、Apple のプライバシーポリシーが適用されます。自分の Google Maps API キーを設定し、Apple マップで結果が得られなかった場合にだけ Google Places を利用し、Google のプライバシーポリシーが適用されます。

これらのサービスには、その検索を完了するために必要な最小限の情報だけを送ります。データを販売したり、開発者の広告やユーザープロファイル作成に利用させたりすることはありません。

端末内の保存と保持期間

ライブラリのスナップショット、確認途中の下書き、操作履歴、タイムゾーンのキャッシュ、設定は、削除するまで Placr のサンドボックスコンテナに保存されます。Google Maps API キーは macOS のキーチェーンに別途保存され、Placr の設定または「キーチェーンアクセス」で削除するまで残ります。

アプリを削除しても、サンドボックスコンテナやキーチェーン項目が自動的に消えるとは限りません。完全な削除方法を以下に示します。

権限の取り消しとデータの削除

  • 写真へのアクセスを取り消す：「システム設定 → プライバシーとセキュリティ → 写真」で Placr をオフにします。
  • Google API キーを削除する：Placr の場所検索設定で削除します。または「キーチェーンアクセス」でサービス名 cn.chenhk.placr.google-places の項目を削除します。
  • Placr の端末内データを削除する：Placr を終了し、Finder の「移動 → フォルダへ移動」で ~/Library/Containers/cn.chenhk.placr を開き、そのフォルダをゴミ箱へ移動します。

写真の権限や端末内データを削除しても、写真に書き込まれた位置情報は元に戻りません。復元したい場合は、データを削除する前に Placr の操作履歴から復元してください。

子どもについて

Placr は子ども向けに設計されておらず、年齢その他の個人情報を収集しません。

ポリシーの変更

このポリシーを変更した場合は、ページ上部の日付を更新します。重要な変更はアプリ内でもお知らせします。

Privacy Policy

Last updated: July 2026

Placr runs entirely on your Mac. There is no developer-operated server, no account, and no way for the developer to receive your photos or usage history.

What is not collected

Placr does not collect, store, or transmit personal information to any server controlled by the developer. There is no analytics, crash reporting, advertising, cross-app tracking, or third-party data collection SDK.

Photos

After you grant access, Placr reads capture times, locations, and thumbnails to find photos missing a location, group them by time, and display reference photos. All processing happens on your Mac. The photos themselves never leave the device.

A location is written only after you approve the candidate and the final batch confirmation. Placr never deletes photos or changes metadata other than location. The previous location is stored in a local operation record so you can restore it.

Place search and third-party services

For a place search, Placr sends only the text you typed. If a reference coordinate is available, it also sends an approximate search region. Photos, thumbnails, and operation records are never sent.

Searches are handled by Apple Maps (MapKit) by default and are subject to Apple’s Privacy Policy. Placr contacts Google Places only if you supply your own Google Maps API key and Apple Maps returns no result; those requests are subject to Google’s Privacy Policy.

Placr provides these services only the minimum information required for the search at hand. It does not sell data or permit requests to be used for advertising or user profiling on the developer’s behalf.

Local storage and retention

The library snapshot, review drafts, operation history, time-zone cache, and preferences remain in Placr’s sandbox container until you remove the files. A Google Maps API key is stored separately in the macOS Keychain until you remove it in Placr Settings or Keychain Access.

Deleting the app may not automatically remove its sandbox container or Keychain item. Complete removal instructions follow.

Revoking access and deleting data

  • Revoke Photos access: open System Settings → Privacy & Security → Photos, then turn off Placr.
  • Remove the Google API key: remove it in Placr’s place-search settings, or delete the item whose service is cn.chenhk.placr.google-places in Keychain Access.
  • Delete Placr’s local data: quit Placr, choose Go → Go to Folder in Finder, enter ~/Library/Containers/cn.chenhk.placr, and move that folder to the Trash.

Revoking Photos access or deleting local data does not undo locations already written to Photos. To restore them, use Placr’s operation history before deleting the local data.

Children

Placr is not directed to children and does not collect age or any other personal information.

Changes

If this policy changes, the date at the top of this page will be updated. Significant changes will also be surfaced in the app.
