按需交付

01 / KEEP

一个清楚的密钥库。

添加 API 密钥、令牌或文件凭据，按名称搜索、按项目分组。显示名可以修改，供命令使用的引用保持不变。

你加入 Credr 的凭据启用 iCloud 钥匙串同步，由 Apple 根据账户和设备设置管理。

02 / CONNECT

连接正在使用的 Agent。

  1. 复制接入说明

    在 App 中打开“连接 Agent”，把说明粘贴给支持 Skill 的 Agent。

  2. 安装文档，检查连接

    Agent 连接完整 Skill 目录，检查 CLI 版本与能力。此步骤不读取密钥值。

  3. 需要时，再批准取用

    每次操作声明调用方和理由，取用时请求系统身份验证。本机调用记录帮助你查看来由。

03 / KNOW

知道交给了谁。

默认不输出明文。环境交付把值传给获准程序；该程序仍能读取并使用它，兼容性受 App Sandbox 限制。

Credr 只管理你加入它的凭据，不读取 Apple“密码”或其他应用的完整钥匙串。查看隐私与使用边界

01 / KEEP

A clear credential library.

Add API keys, tokens or file credentials. Search names and group projects. Edit display names while keeping command references stable.

Entries you add to Credr have iCloud Keychain synchronization enabled. Apple manages sync according to account and device settings.

02 / CONNECT

Connect the agent you use.

  1. Copy instructions

    Open Connect Agent in Credr and paste the instructions into a Skill-capable agent.

  2. Install docs and check access

    The agent connects the entire Skill directory and checks CLI versions and capabilities, without reading values.

  3. Approve when a value is needed

    Each operation declares a caller and purpose. System verification precedes release. Review local request history.

03 / KNOW

Understand the destination.

No plaintext output by default. Environment delivery supplies values to approved tools that can read them. App Sandbox still limits tool compatibility.

Credr manages only entries you add to its group. It does not browse Apple Passwords or other apps' private Keychain records. Read privacy and use boundaries.

The current app interface is in Simplified Chinese.
