SUPPORT

使用帮助

遇到问题或有建议，请联系 imhccn@gmail.com。附上 macOS 版本、Credr 版本与操作步骤；请勿发送密钥值。

怎样连接 Agent？

在 Credr 打开“连接 Agent”，复制说明并粘贴给正在使用的 Agent。Agent 按自己的 Skill 目录规则安装完整文档并检查连接。已有冲突文件应保留，不自动覆盖。移动或升级 App 后重新复制说明。

为什么查到了名字，却没有值？

默认查询只返回名称和元数据。取用值需要 Touch ID 或系统密码。让 Agent 优先使用 run --env 交给目标程序；明确需要原始值时可用 get --stdout，注意选择接收位置。

命令为什么要求 caller 和 reason？

每次业务操作都必须声明调用方、实际运行环境和理由，供你在取用提示与调用记录中查看。它们属于调用方自报信息，不代表经过身份认证，也不能代替系统验证。

为什么目标命令不能启动？

Credr 使用 App Sandbox。某些程序、配置文件或目录可能无法访问。“检查本机访问”只检查元数据能力，不证明任意工具都能运行。请分享不含密钥的静态错误和诊断，不要通过关闭沙盒解决。

可以读取“密码”里的所有密码吗？

不可以。Credr 只管理你添加到它的 Keychain 共享组的凭据，不自动导入其他应用或 Apple“密码”的记录。

iCloud 同步怎样开启？

在参与同步的设备使用同一 Apple 账户，并开启“密码与钥匙串”。Credr 不能验证每条凭据的远端到达时间。当前产品是 Mac 应用，工程里的 iOS 宿主仅用于共享层测试。

怎样删除数据？

在 App 里明确删除凭据；操作可能同步传播到其他设备，且无法由 Credr 撤销。本机调用记录可以在“调用记录”中关闭并清空。卸载 App 不等于删除所有 Keychain 凭据。

怎样提供诊断？

“设置 → 关于 → 诊断”可以复制不读取值的访问诊断。诊断可能含 App 路径、签名和访问组；分享前检查。请勿附带真实凭据、环境变量或含令牌的命令输出。

SUPPORT

Help with Credr

Contact imhccn@gmail.com with your macOS version, Credr version and reproduction steps. Never send credential values.

Connect an agent

Open Connect Agent, copy instructions and paste them into your agent. It installs the entire Skill directory using its own conventions and checks access. Preserve conflicting files. Repeat after moving or upgrading the app.

Names without values

Queries return metadata by default. Releasing values requires Touch ID or your system password. Prefer run --env for delivery to an intended tool. Use get --stdout only when raw access is explicitly requested.

Caller and reason

Every operational command declares its caller, environment and purpose. These are self-reported information for prompts/history, not authenticated identity or substitutes for system verification.

Command compatibility

App Sandbox can restrict executables, configuration files and directories. A metadata probe does not prove that every tool works. Share static errors and sanitized diagnostics; keep sandboxing enabled.

Storage and sync

Credr only manages records added to its own Keychain group. It does not browse Apple Passwords. Apple manages iCloud Keychain synchronization according to your device settings. Credr cannot verify per-entry remote completion. This is a Mac app; the iOS target in the project is a test host.

Delete data and share diagnostics

Deleting a credential may propagate to other devices and cannot be undone in Credr. Turn off or clear local history in Request History. Uninstalling is not a guarantee of Keychain deletion. Settings can copy metadata-only diagnostics; inspect local paths and signing facts before sharing. The current app interface is in Simplified Chinese.
