Focus

在做什么

01

图文创作 Agent 系统

设计 Planner + Function Calling 的模块化智能体架构，支持多轮任务规划与工具并发执行，落地于豆包「超能创意」、即梦「创作 Agent」等功能，并复用至 Pippit、剪映等场景。

02

AIGC 数据工程与标注

构建高质量图文配对筛选与协议化合成链路，训练具备 Grounding 能力的多模态标注模型，为 DreamPoster、ETTA 等文生图模型提供百万级结构化训练数据。

03

开放式输入建模

把用户自由输入转化为模型「最擅长处理」的结构化 Prompt，通过 SFT + DPO 训练偏好驱动的输入模块，支撑 DreamPoster 传图海报可用率达 88.55%。
